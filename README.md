- Welcome to DME explorer, the web application for viewing and exploring the curriculum, courses, programs, news and the facilities inside the faculty of Digital Media Engineering, Khon Kaen university
- Rather than navigating the multiple websites to find the information about the curriculum, this website will provide the various information and user can also explore and interact with the facilities (CDLC room) and connect to many users via the multiplayer mode and chat together throught the live chat inside the 3D relax zone page
- Usee can also explore the environment in multiplayer mode and interact with the environment around faculty of Digital Media Engineering.


This project is a part of final project for EN842300 (Interactive Web Programming) course in academic year of 2026, Khon Kaen university, faculty of Engineering, Digital Media Engineering. We hope you enjoy using our website ^^.
